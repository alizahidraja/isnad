  tightening). It can no longer affirm CONSISTENT, so its cold-start coverage is **0%** —
  every clean claim is held for review. This is a real, deliberate trade: the critic can no
  longer bless a hallucination (0.000 false-consistent), but it also can no longer *serve*

- **The seed fix (#114) still works**: the seeded chain grades ḥasan, not ḍaʿīf — the
  bottleneck is now entirely the critic's ability to say CONSISTENT.
